## Overview

This project demonstrates the core data management capabilities required for the NET Service Data Manager role at Cardiff and Vale UHB. It was built as a tangible portfolio piece showing:

- Synthetic clinical dataset generation modelled on ENETS Centre of Excellence data requirements
- Automated data quality validation with 10 clinically meaningful rules
- Statistical analysis and chart-ready exports
- Power BI dashboard (3 pages) covering service overview, ENETS compliance, and query management
- A one-page written proposal for data management approach in the first 30 days

> **All patient data is entirely synthetic and fictional.** No real patient data was used at any point.

## What each script does

### Script 01 — Synthetic data generation
Generates 150 fictional NET patients with 19 clinical fields including tumour site, WHO grade (G1/G2/G3), Ki-67 index, stage, treatment modality, ENETS field completeness status, referring health board, and outcome. Fields are distributed to reflect realistic clinical patterns (e.g. 45% stage IV, 22% incomplete ENETS fields, 4 deliberate date errors).

### Script 02 — Automated data quality checks
Runs 10 validation rules directly analogous to edit checks in regulated clinical trials (Medidata Rave / Viedoc). Each rule maps to a real ENETS or clinical governance requirement:

| Rule | Field checked | Severity |
|------|--------------|----------|
| R01 | Incomplete ENETS mandatory fields | High |
| R02 | Overdue follow-up (>365 days) | Medium |
| R03 | Treatment start before diagnosis | High |
| R04 | G3 tumour on Watch & Wait | High |
| R05 | MDT not discussed (>30 days post-dx) | Medium |
| R06 | Stage IV with no treatment recorded | High |
| R07 | Chromogranin A not measured | Medium |
| R08 | Ki-67 / grade mismatch (WHO 2022) | High |
| R09 | Lost to follow-up on active treatment | Medium |
| R10 | No imaging recorded at diagnosis | Low |

Outputs: `query_report.csv`, `quality_summary.csv`, `enets_readiness.csv`

### Script 03 — Statistical analysis
Produces 9 aggregated datasets for Power BI import, covering tumour profile, treatment distribution, monthly registration trend, health board referrals, follow-up gap distribution, outcome by grade, ENETS field-level completeness, and the master Excel workbook with all sheets.

### Script 04 — One-page proposal (Word)
Generates a formatted A4 Word document (`NET_Data_Management_Proposal.docx`) with Cardiff and Vale UHB branding (navy #003087, gold #C8A951) containing: current challenge, KPI snapshot table, proposed data architecture, ENETS field compliance table, and a 30-day action plan. Intended to be printed or shown in the interview.

## Power BI dashboard

The dashboard has three pages built from `powerbi_master.xlsx`:

**Page 1 — Service Overview**  
KPI cards (total patients, ENETS readiness %, MDT rate, open high queries) + tumour site donut, grade bar chart, treatment modality, health board referrals, monthly registrations trend.

**Page 2 — ENETS Compliance Tracker**  
Gauge chart showing submission readiness % vs 90% target, field-level completeness horizontal bar with threshold line, per-patient submission status table with RAG conditional formatting, completeness trend by year.

**Page 3 — Data Quality**  
Open queries by rule and severity (stacked bar), query volume cards, full open query log table (sortable, filterable), query type pie chart.

See `docs/POWERBI_SETUP_GUIDE.md` for full step-by-step build instructions.

## Clinical context

This project reflects genuine understanding of the clinical and governance landscape of the role:

- **ENETS Centre of Excellence accreditation** requires annually submitted, validated patient data across mandatory fields. The ENETS compliance page of this dashboard directly addresses the submission readiness monitoring required by the JD.
- **WHO 2022 NET grading** (G1/G2/G3 based on Ki-67 index) is reflected in Rule R08, which flags grade/Ki-67 mismatches — a real data quality issue in clinical registries.
- **NHS Wales JCC service specification** requires monthly reporting to the Lead Consultant, Service Manager, and Finance/Commissioning teams — mirrored in the monthly registrations and health board referral outputs.
- **Caldicott Principles and GDPR** are reflected in the data architecture proposal and the handling of patient-identifiable data fields.
- The author's MSc final-year project on **L-cell hormone release in human colonic biopsies** (neurogastroendocrinology) provides direct scientific grounding in the enteroendocrine biology underpinning GI-origin NETs.
